        <p class="lp-pane-note">A pull request opens. The agent reviews the diff from inside the checkout and comments back. Read-only tools — it can look, not touch.</p>

```ts title="acme-app/.steerium/workflows/pr-review.ts"
import { defineWorkflow, github } from "steerium";

export default defineWorkflow({
  name: "pr-review",
  on: github.prOpened({ repo: "acme/app", intervalMs: 60_000 }),
  timeoutMs: 15 * 60_000,
  async run(ctx) {
    const { pr } = ctx.event;

    await ctx.step("fetch", () => exec("git", ["fetch", "origin", pr.branch]));

    const review = await ctx.step("review", () =>
      ctx.agent.run({
        provider: "claude",
        allowedTools: ["Read", "Grep", "Bash"],
        prompt: `Review PR #${pr.number} ("${pr.title}") on ${pr.branch}.
                 Diff against ${pr.baseBranch}. Correctness bugs and risky
                 changes only — skip style nits.`,
      }),
    );

    const { token } = ctx.connector<{ token: string }>("github");
    await ctx.step("comment", () =>
      github.comment(token, pr.repo, pr.number, review.text),
    );

    await ctx.artifact.writeText("review.md", review.text);
  },
});
```

      <div class="lp-pane">
        <p class="lp-pane-note">A ticket moves to Todo. A cheap model plans, a coding agent implements on a branch, and the ticket gets told what happened. <code>concurrency: 1</code> keeps one agent in the repo at a time — the rest queue.</p>

```ts title="acme-app/.steerium/workflows/ticket-agent.ts"
import { defineWorkflow, linear } from "steerium";

export default defineWorkflow({
  name: "ticket-agent",
  on: linear.ticketMoved({ to: "Todo", intervalMs: 60_000 }),
  concurrency: 1, // one agent in the repo at a time
  timeoutMs: 45 * 60_000,
  async run(ctx) {
    const { ticket } = ctx.event;
    const branch = `steerium/${ticket.identifier.toLowerCase()}`;

    const plan = await ctx.step("plan", () =>
      ctx.agent.run({
        provider: "openai", // cheap model for the thinking
        prompt: `Draft an implementation plan for ${ticket.identifier}:
                 ${ticket.title}\n\n${ticket.description}`,
      }),
    );

    await ctx.step("branch", () => exec("git", ["checkout", "-B", branch]));

    await ctx.step("implement", () =>
      ctx.agent.run({
        provider: "codex", // real coding agent, chosen per call
        prompt: `Implement this plan, then run the tests:\n\n${plan.text}`,
      }),
    );

    const { apiKey } = ctx.connector<{ apiKey: string }>("linear");
    await linear.comment(apiKey, ticket.id, `Pushed to \`${branch}\`.`);
  },
});
```

      <div class="lp-pane">
        <p class="lp-pane-note">Not everything needs a model. This one is plain Node and git on a six-hour interval — but it still gets the run history, the logs, and the replay.</p>

```ts title="~/.steerium/workflows/repo-housekeeping.ts"
import { defineWorkflow, schedule } from "steerium";
import { execFile } from "node:child_process";
import { promisify } from "node:util";

const exec = promisify(execFile);

export default defineWorkflow({
  name: "repo-housekeeping",
  on: schedule.every(6 * 60 * 60_000),
  async run(ctx) {
    const pruned = await ctx.step("prune-merged-branches", async () => {
      await exec("git", ["fetch", "--prune"], { cwd: ctx.scope.cwd });
      const { stdout } = await exec("git", ["branch", "--merged", "main"], {
        cwd: ctx.scope.cwd,
      });
      const branches = stdout
        .split("\n")
        .map((b) => b.trim())
        .filter((b) => b && !b.startsWith("*") && b !== "main");

      for (const b of branches) {
        await exec("git", ["branch", "-d", b], { cwd: ctx.scope.cwd });
      }
      return branches;
    });

    await ctx.artifact.writeJSON("pruned.json", pruned);
    ctx.logger.info(`pruned ${pruned.length} merged branch(es)`);
  },
});
```

      <div class="lp-pane">
        <p class="lp-pane-note">Waiting for a human isn't a paused process. <code>approvals.request</code> posts the question and the run <em>ends</em>. Your reply is a new event that fires a second workflow — so waiting survives restarts, sleep, and reboots.</p>

```ts title="~/.steerium/workflows/blog-approve.ts"
import { defineWorkflow, approvals, isApprove } from "steerium";

export default defineWorkflow({
  name: "blog-approve",
  on: approvals.responded(),
  async run(ctx) {
    const { approval, reply } = ctx.event;
    const { draft } = approval.payload;

    if (isApprove(reply.text)) {
      await ctx.step("publish", () => commitAndPush(draft));
      await approvals.resolve(ctx, approval.id);
      return;
    }

    // Anything that isn't approval is treated as feedback: revise and re-ask.
    const revised = await ctx.step("revise", () =>
      ctx.agent.run({
        provider: "anthropic",
        prompt: `Revise this draft.\n\nFeedback: ${reply.text}\n\n${draft}`,
      }),
    );

    await approvals.reask(ctx, {
      id: approval.id,
      text: "Review the revised draft.",
      payload: { ...approval.payload, draft: revised.text },
      options: [{ value: "approve", label: "Approve and publish" }],
      display: {
        kind: "markdown",
        title: "Revised draft",
        content: revised.text,
      },
      allowFreeform: true,
    });
  },
});
```

<section class="lp-section">
  <div class="lp-head">
    <p class="lp-eyebrow"><span>05</span> Model</p>
    <h2 class="lp-h2">Three primitives — and you can replace all of them</h2>
    <p class="lp-lede">The built-ins hold no privileged access. Every one of them is written against the same public API you get, so anything shipped is a worked example rather than a wall.</p>
  </div>

<div class="lp-model">
  <div class="lp-prim">
    <span class="lp-prim-n">Trigger</span>
    <p class="lp-prim-d">Emits events.</p>
    <ul>
      <li>cron &amp; intervals</li>
      <li>GitHub, Linear, Jira</li>
      <li>webhooks (HMAC-verified)</li>
      <li>approval replies</li>
      <li>manual fires</li>
    </ul>
    <p class="lp-prim-ext">
      <code>defineTrigger</code> — implement <code>start(ctx, emit)</code> and
      you get persistent state for dedup cursors and webhook registration for
      free.
    </p>
  </div>
  <div class="lp-prim">
    <span class="lp-prim-n">Workflow</span>
    <p class="lp-prim-d">Handles one event.</p>
    <ul>
      <li>an async function</li>
      <li>typed events and outcomes</li>
      <li>steps, logs, artifacts</li>
      <li>any npm package</li>
      <li>shell, git, fs</li>
    </ul>
    <p class="lp-prim-ext">
      <code>defineWorkflow</code> — there is nothing to extend here, because
      there was never a DSL in the way.
    </p>
  </div>
  <div class="lp-prim">
    <span class="lp-prim-n">Provider</span>
    <p class="lp-prim-d">Runs an AI or agent call.</p>
    <ul>
      <li>
        <code>openai</code>, <code>anthropic</code>
      </li>
      <li>
        <code>claude</code>, <code>codex</code>
      </li>
      <li>
        <code>mock</code> (the default)
      </li>
      <li>typed structured output</li>
      <li>chosen per call</li>
    </ul>
    <p class="lp-prim-ext">
      <code>defineProvider</code> — a local model, an internal inference
      service, a different agent. Register it in config; workflows just name it.
    </p>
  </div>
</div>

<ol class="lp-loop">
  <li>
    <span>1</span> an event arrives
  </li>
  <li>
    <span>2</span> deduped and persisted
  </li>
  <li>
    <span>3</span> your function runs, step by step
  </li>
  <li>
    <span>4</span> it ends <code>succeeded</code>, <code>failed</code>,{" "}
    <code>cancelled</code>, or <code>timed_out</code>
  </li>
  <li>
    <span>5</span> replay the same event, with both runs' provenance recorded
  </li>
</ol>

<p class="lp-footnote">
  No automatic retries, deliberately: agents commit code, push branches, and
  leave comments, so a blind retry duplicates all of it.{" "}
  <code>steerium replay &lt;runId&gt;</code> is the explicit re-run. Replay
  keeps the original event, but uses the code and provider configuration loaded
  now; compare the two provenance records when exact reproducibility matters.
</p>

  <div class="lp-agentic">
    <p class="lp-agentic-lead">And you don't have to write any of it by hand.</p>
    <p class="lp-agentic-body">A workflow is a plain TypeScript file with a typed API and no DSL to learn, which makes it the kind of thing a coding agent is genuinely good at producing.
